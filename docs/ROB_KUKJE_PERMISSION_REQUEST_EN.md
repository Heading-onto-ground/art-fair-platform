ROB is an art-history search and exploration service. It structures publicly documented exhibition history and links each record back to the original page.

We would like permission to store and display minimal factual exhibition metadata from Kukje Gallery's public pages. The fields are artist names, exhibition names, dates, venues, participants when the page states them, and the source URL. Each record would link back to Kukje Gallery.

ROB will not reproduce images, artworks, press-release text, biographies, or curatorial essays.

We are asking for permission for this source as a whole, so later factual exhibition metadata from Kukje Gallery can be handled in the same way. The first pages are:

- https://www.kukjegallery.com/artists/view?seq=190
- https://www.kukjegallery.com/artists/view?seq=181
